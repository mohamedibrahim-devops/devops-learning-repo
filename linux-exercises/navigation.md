# Linux Navigation

This section covers the Linux navigation commands i've learned and used during my DevOps studies

## Commands

### 'pwd'
Shows the full path of current directory your working in.

### 'cd'
Changes the current directory

### 'cd ..'
Go up a directory.

### 'cd ~' 
Takes you to the home directory.

### 'ls'
List files and folders in the current directory.

### 'ls -a'
Shows hidden files too.

### 'ls -la'
Shows everything in detailed format.
 
### 'mkdir'
Creates a new directory.

### 'rmdir'
Deletes an empty directory.

### 'cp'
Copies files or directories.

### 'echo'
Displays text.

### 'mv'
Moves or renames files directories.

### 'touch'
Creates and empty file.

### 'rm'
Deletes files 

### 'cat'
Displays content of a file.

### 'head'
Shows first few lines of a file.

### 'tail' 
shows last few lines of a file. 

### 'grep'
Searches for specific texts inside a file.

### 'vim'
Opens a file in the vim text editor, allowing you to view or edit it.

### 'find'
locates files and directories.

### 'chmod'
Changes the permission of a file or a directory.

### 'chown'
Change ownership of a file or a directory.

### 'sudo'
Runs command with elevated privileges.
